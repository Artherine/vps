## 已知的坑（别再踩）

1. **表单域的 CJK 渲染不可靠**：PyMuPDF 只能拿内建 CJK 字体写外观流，某些查看器会把中文**横向拉伸并吞字**（曾复现）。要中文清晰就走打印版（真嵌入雅黑）。
2. **复选框的值**：未勾选在 PyMuPDF 里返回字符串 `"Off"`——**在 Python 里是真值**。判断时必须排除 `Off/False/None/""`，否则会把整张表点满（踩过一次，100 个点）。
3. **六个豁免的字段名分不出属性**（`SavingThrows` / `SavingThrows2..6`），必须按 y 坐标与 `STR/DEX/CON/INT/WIS/CHA` 对齐。
4. **嵌入系统字体会让文件暴涨**（整套雅黑 ≈ 13 MB）→ 保存前必须 `doc.subset_fonts()`。
5. **第三页是法术页**，罗斯科当前为空——按用户要求保留（万一兼修神术或剧情觉醒）。
