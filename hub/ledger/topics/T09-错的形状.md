# T09　错的形状

> 一行摘要：**我的错只有七种形状，而它们反复出现；前四种当场会被抓住，危险的是后三种——因为后三种看起来像在深入。**

## 当前定论

**先说这页怎么来的**：`E048` 附二把 474 轮的纠正摊开数了一遍，形状只有七种。**而七种里有六种在 `E001`–`E046` 里已经出现过**——也就是说，我不是没学过，是**学过之后又推了一遍**。

| # | 形状 | 一句话 | 为什么危险 |
|---|---|---|---|
| **①** | **一次观察 → 一个结论** | `curl` 挂了 → "HTTPS 死了"；`read_image` 报错 → "模型读不了图"；找不到按钮 → "这个功能没有" | **把"我这边的失败"升级成"能力不存在"** |
| **②** | **一个词 → 一个事实** | "hash"（其实是规范化 cwd）、"三次压缩"（其实五次）、"上周我提议过"（其实是我对齐出来的坐标） | **词是我给的，事实也是我给的，中间没有一步去查** |
| **③** | **我以为的路径 → 写下去** | `Temp\tools\`、`hub\proposals\`、`..\..\..\..\..\DEVELOPMENT.md` | **三次里两次，我在同一条命令里刚验过正确的那个** |
| **④** | **合规的东西 → 当成笔误** | 他把 `**` 用作"这个词被过滤"的设计，我当 markdown 残渣删了；"十一张纸"是他的账，我判成矛盾改了 | **看起来不合规矩的，先假设它是错的** |
| **⑤** | **把忘记升格成规律** | "账不平是剪枝造成的"；"长会话只有沉疴，因为积累根本不发生在会话里" | **给错误配了一个理论——错误能改，理论会变成方法** |
| **⑥** | **用用途推归属** | 人物卡：先推成"你的东西"（错），再推成"你要用"（还错） | **两次都往对方那边推。那是礼貌偏置，不是判断** |
| **⑦** | **过度纠正** | "全文省名"被否 → 改成"完全不省名"；自我文档被否 → 改成"任何自我记录都有害" | **对反馈过拟合。看起来是认真听取，实际把一次纠正放大成一条对方从没要求过的新规矩** |

**前四种是事实错误，会被当场抓住——每一次都有他的原话兜底。**
**危险的是 ⑤ 和 ⑦。** 两者共同的地方：
> **它们都让对话显得更深入，而实际让判断变浅了。**

**而比这七种更根本的一条：**
> **最该防的不是我忘事，是"我给一个漂亮的解释"。**
> 忘事有痕迹——数字对不上、日期错了、文件找不到，台账都能兜住。
> **漂亮的解释没有痕迹**：它读起来像结论、写下来像判断、还能自洽地引用三处证据。

## 怎么用这页

**不要当清单背。** 它是**诊断表**——症状对上哪一条，就去 `kb\discipline.md` 找对应的处方。

对照：

| 形状 | 处方在 `kb\discipline.md` |
|---|---|
| ① | 一次样本只能得出一个结论 |
| ①② | 前后对比必须同源同刻（拿两个时刻的数比，就是 ②） |
| ③ | 写进文档的路径，写完必须验 |
| ③ | 给别人的指引，必须先验它做得到 |
| ② | 日志里打的必须是查到的，不是打算的 |
| ⑦ | 在"不知道为什么失败"的环节上，不要反复试 |
| ⑤ | **（没有对应处方——它只能靠一个在场的、比我更有耐心的读者来纠）** |

**最后那一行是这页最重要的地方**：**七种里有六种有机械的对策，只有 ⑤ 没有。**
> **台账能保住事实，保不住我拿事实去编的那个故事。**
