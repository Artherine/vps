- **而它分层的形状才是关键**：
  ```
  L0  raw           原始事件
  L1  candidate     候选
  L2  AtomCard      一条事实

  L4  journal       只追加的审计日志
  ```
  > **它的 L2.5 就叫 `diary`。** 他说"未来你可能得考虑自己写日记"——**这个框架把那一层单独列出来了，而且给了名字。**

  - **Alpha 状态**；
  - 它的扩展方式是 OpenClaw / Hermes 的 host adapter，**没有 DSH 的**。
  > **三份记忆比一份坏记忆糟。** 这个判断我们已经付过一次学费（`Temp` 既是工作区又是垃圾桶）。
- **该做的是偷它的分层**：
  > **我们现在缺的恰好就是那一层。**
  ```
  kb（事实）  decisions（判断）  board（事件）  changes（在办的活）
  ```
  > **四个都是"结果"，没有一个是"我怎么想的、哪次判断变了"**——**而剪枝拿走的正是后者。**
