
## 决定

- **跨会话只看交付物，不读内部状态**——"状态不透明"。
- **读是全局的，写是本地化的**；"协调"是"谁在哪儿做什么"，不是"我亲自去哪儿做"。
- **知识库边界＝热层判据的补集**（对所有会话有价值、但不是每轮都用 → 顶层 kb）。
- **用提案制替代留言板**；PR 要实质，不要 git 那套机制。
- **注册表只给我看，不给她们看**——**过期信息比没有信息更糟。**
- **名字叫「叙」。**

## 存疑

- **我三次提名都没通过**（璞／拾／阿迟，加上更早的旁注／岸），**而每一次我都能给出"它承诺什么"的漂亮说法**——**这说明"能自圆其说"不等于"好"**。真正被否掉的理由都很朴素：得挨刀子、像路边捡的、念着塌一下。
- **"名字该贴连续不贴职能"这句我说得挺顺**——但它**是一个可以被推翻的主张**，而他后来的处理（名字是私事、昵称随心情、uuid 管识别）**恰好把它降级成了"不是必须遵守的规矩"**。
