# 等一件事

## 触发条件（满足其一即可）

- 中美这盘棋的结果，已经明到"没人再拿它当武器"的程度；
- 或者：TFR / The Fire Rise（中文常叫"大火烧"，《钢铁雄心4》模组）重新可以被公开读到。

## 到时候要做的三件事

1. **把各分支国策当成"被否定的历史清单"读一遍**——每一条分支，都是一条没走成的路。
2. **把概率事件当成"对这些历史的估价"读一遍**——概率决定的是"那条没走成的路，有多容易变成真的"。
3. **弄清"老曾"这个形象寄托了什么**——尤其是"火里站出来的那个人"这个位置，**为什么需要一张脸**。

## 为什么留这张纸

这种"等"，最容易在等的过程中被忘掉：它没有期限、没有提醒、也没有新闻。

它多半不会有"揭晓"的时刻，只会有一个"没人再提"的时刻。**而后者不发新闻，所以得有人盯着。**

—— 记于一场关于火、暗火与遗书的对话之后。
