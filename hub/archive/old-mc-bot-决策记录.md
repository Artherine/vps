## 一、目标与顺序

让 LLM 在 MC 里动起来。顺序定死为：**先“看得见”，再“动”**——因为错全是“看错”造成的，不是“动不了”造成的。

## 二、架构决定：文件命令队列

```
LLM  ──写──>  cmd.txt  ──轮询──>  bot  ──写──>  out.txt  ──读──>  LLM
```

**为什么这么做**：实测延迟——**bot 内部 1 ms、轮询 100 ms、我这一跳（一次工具调用）秒级**。

→ **瓶颈在我，所以我做不了“反应”，只能做“决策”。**
→ **快环（卡住、掉血、下落）必须留在 bot 内，不等我。**

这是“皮层不能当脊索用”的直接落地。

## 四、“我在哪儿”——三次同一个错

```
1. 忘了看脚下          → 站在树顶上，不知道
2. 只看脚下            → 脚下有叶子撑，身体那格被叶子卡住
3. 用中心点代替包围盒    → 中心点是 air，其实靠旁边一格撑着
```

**规律：不看 → 只看一点 → 用点代替体积。**

**结论**：玩家碰撞箱 **0.6 × 1.8 × 0.6**（水平半径 0.3）；**“站住”要按包围盒覆盖的 1–4 列判，不许用中心点**。
