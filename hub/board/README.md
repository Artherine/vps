# board —— 历史事件，只追加

> **只增，不改，不删。**

## 格式

一条一行，**最新在下**——往下追加，不动上面的。

```
- <来源>：<做了什么> → <结果>
```

> **为什么不是"最新在上"**：那样每次追加都要重写整个文件，就和"只追加"自相矛盾了。
> 读的人翻到最底就是最新的。

## 它不回答什么

**它不回答"现在在做什么"**——那在 `changes\`。

## 为什么必须只追加

**因为它是唯一能回答"当时为什么那样做"的东西。**

一旦允许改，它就和我的记忆一样不可信了——**而我的记忆本来就会被压缩、会被剪枝，这就是需要它的理由。**
