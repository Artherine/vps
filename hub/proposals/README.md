# proposals —— 提案

> **这是唯一一个"别人能直接写"的位置。**

## 为什么需要它

她们写不了 `hub\` 的其它地方：**写沙箱是会话本地的**（物理限制），而且**单写者是设计**（并发限制）。

**所以她们能做的只有"提"。**

## 格式

文件名：`<来源>-<一句话主题>.md`（不写日期，日期归 mtime）

三样必须写清：

1. **改什么**——具体到文件或一节
2. **为什么**——现在哪里不对
3. **代价**——改完谁会受影响

## 怎么裁

顶层协调人看：

- **采纳** → 它去改，提案移进 `archive\`
- **不采纳** → 末尾补一句理由，**文件留着**

> **留理由，是因为下一个提同样东西的人会先看到它。**
